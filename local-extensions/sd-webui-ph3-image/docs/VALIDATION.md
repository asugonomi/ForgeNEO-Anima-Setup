# 検証記録

対象: P-H3 Image Native for Forge Neo 0.1.0-experimental  
作成日: 2026-11-05

## 結論

**CPUテスト66件成功、Python構文コンパイル成功。実モデルのGPU画像生成は未実施です。**

RTX 4070 Ti SUPER 16GB + RAM 64GB、Windows、Forge Neo本体の実環境での生成成功を示す記録ではありません。他実装の16GB動作報告を、この拡張の動作検証に置き換えてはいません。

## 実テンソル・実ファイルで確認したこと

小さいCPUテンソルを使用してTextConnectorの正規化・射影・先頭トークン置換、画像の位置座標、サンプラーの8ステップ・速度の符号・固定Seed、NaN出力の拒否を検査しました。

小さいsafetensorsファイルのヘッダー、破損・途中切れの拒否、PNGのparametersメタデータとJSONの保存を実ファイルで検査しました。厳格なキー読込とFP32パラメータ復元も小型の実torch.nn.Moduleで検査しました。

Gradioの専用タブ構築、コールバック引数、設定保存も確認しました。ただし、これはForgeの起動プロセス内でのUI互換性確認ではありません。

## 模擬実装で確認したこと

Forgeのバックエンド、GPUメモリAPI、大規模DiT、ダウンロード通信を小型の模擬実装に置き換えたテストを含みます。

確認した範囲は、共有ロックを保持して実行する制御、停止時の後始末、OOMの1回再試行、Seedと解像度の維持、解放失敗を成功扱いにしない処理、CPUキャッシュの削除設定、Qwenの隠れ状態を選択する位置、VAEの単一フレーム出力形状、セットアップ時のスクリプト除外・パス逸脱拒否・チェックサム検証です。

これらのテストで報告される模擬メモリ量は、実GPUの測定値ではありません。ヘッダー分類テストの一部も模擬ヘッダーであり、実モデル重み全体のロード結果ではありません。
