# このPC向け画像編集版

公開タブは「P-H3 画像編集」。メイン画像1枚、追加参照画像0〜7枚、編集指示、画像サイズ倍率、Seed、結果枚数を指定する。
画像1はメイン画像、画像2〜8は追加欄の表示順。出力サイズの基準はメイン画像。
文章だけから生成するUI/APIは登録しない。モデルパス、メモリ設定、診断は折りたたんで表示する。

倍率適用後の各辺を32の倍数に四捨五入（ちょうど中間は上）し、実際の出力サイズを操作画面に表示する。
各辺256〜4096、900万画素以下の制限を超えた場合はエラーにし、黙って縮小しない。
入力のEXIF向きを適用し、RGBに変換する。出力用の参照潜在と視覚エンコーダー用の縮小画像は別に作る。
視覚用は上流の100万画素目安、参照潜在用は出力画素数を上限の目安にし、どちらも32単位。

処理順: 入力VAEエンコーダー → 視覚・文章エンコーダー → DiT → 出力VAEデコーダー。
段階ごとにForgeのModelPatcherでGPUから退避し、全モデルを同時にGPUへ常駐させない。
入出力VAEはタイル処理。入力VAEの事後分布サンプリングは上流P-H3同様の固定Seed 42。
出力の生成Seedとは別であり、両方を結果JSONへ記録する。
画像の視覚埋め込み、DeepStack、interleaved M-RoPE、視覚トークンタグ、参照潜在を利用する。
通常のimg2imgのノイズ強度方式ではなく、参照画像と文章指示による編集。
ステップ数は従来同様の専用8ステップ。Forge共有生成ロック、停止、例外・OOM時の後始末を利用する。

参照した公式実装:
- https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/text_encoders/minimax.py
- https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/ldm/minimax/vae.py
- https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_minimax_h3.py

これらは処理仕様の参照であり、ComfyUIの起動や処理委譲はしない。

## 参照画像から構図を作成

別のサブタブで参照画像1〜8枚、場面指示、出力の幅・高さを独立指定する。
メイン画像は要求せず、参照画像の寸法から出力寸法を決めない。32の倍数以外は拒否し、勝手に変更しない。
同じモデルの参照条件付け経路を使うが、特定画像の編集接頭辞は付けず、新しい構図を作る指示を加える。
4MP・8MPのサイズ候補は利用者がボタンで適用したときだけ幅・高さへ反映。
同じRTX 4070 Ti SUPERで実GPU検証済み（2026-11-05）:
- 2枚参照、メイン画像なし、2048×2048: 71.15秒。2人が肩を組んでピースする構図を目視確認。
- 同じ指示・Seed、2912×2912: 102.31秒、Torch allocated peak 10.22GiB。解像度に伴い表情や構図も変化。
- 4枚参照、3552×2368: 171.03秒。指定の4キャラクター全員が室内の食卓で食事する構図を目視確認。
  4枚の条件埋め込みは4385トークン。作業用VRAM目安8GiB、VAEタイル256、8ステップ、Seed123456。
  Windowsサンプル最大: 専用VRAM10.22GiB、共有GPU0.435GiB、プロセスRSS25.18GiB。
  Torch allocated peak 9.52GiB。OOM再試行なし。終了後GPU退避、CPUキャッシュは設定通り保持。
Windowsカウンターは約1〜2秒間隔のサンプルであり、瞬間ピークの保証ではない。
5〜8枚の実生成、bf16/int8 DiTとの画質比較は未検証。元絵の画風や細部の完全保持を保証しない。

## 入力と保存先の互換修正

Forgeのsave_pil_to_fileはGradio 4.40の画像入力が渡すname引数を受け取れない。
この拡張の画像入力コンポーネントだけで、Gradioがキャッシュ検証済みのアップロードを再保存せず利用する。
ファイルを実際に画像として開いて検査し、壊れた画像は拒否する。Forge本体のグローバル関数は変更しない。
GradioのメタクラスがWindows既定文字コードでソースを読むため、独自コンポーネントはASCIIの専用ファイルへ分離。

保存先: Settings → P-H3 画像編集 → P-H3画像編集の保存先。
既定値は通常のtxt2img出力先の隣のp-h3-images。各画像をその下のYYYY-MM-DDへ保存する。
このPCでは G:\Stable_diffusion_outputs\p-h3-images\YYYY-MM-DD。
過去のtxt2img-images/p-h3-image以下の生成物は移動・削除しない。
