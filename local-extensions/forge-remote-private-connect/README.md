# ForgeNEOと一緒にスマホ接続を開始する

1. このフォルダーを、利用するForgeNEOの extensions フォルダーに入れます。
2. 普段の方法で、APIを有効にしたForgeNEOを起動します（起動引数 --api）。ForgeNEO本体のポートをインターネットに公開する必要はありません。
3. すでに登録したスマホは、同じWi-Fiまたは接続済みのTailscaleから開けます。新しいスマホを初回登録するときだけ、同じ版のPC用CMDからQRを表示します。

Windowsで、登録したときと同じユーザーでForgeNEOを起動してください。PC再起動後もForgeNEOを起動すれば待ち受けを再開します。停止するにはForgeNEOの拡張機能一覧でこの拡張を無効にして再起動してください。Windowsへの自動起動登録はありません。

対象は標準ポートのAndroid版です。Wi-Fiと有線LANなど物理ネットワーク候補が複数ある場合、自動のLAN待ち受けは保留されます。Tailscaleは個別に確認されます。独自のポートや辞書パスを手動指定している場合は従来の起動方法も使えます。
